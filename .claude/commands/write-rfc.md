# Write RFC

## Objective

実装前に目的、選択肢、tradeoff、rollout を明確にする RFC を作る。

## Context To Gather

- problem statement
- users and stakeholders
- current system
- constraints
- alternatives

## Steps

1. problem と goal を短く定義する。
2. requirements と non-goals を分ける。
3. options と tradeoffs を比較する。
4. 推奨案と migration path を書く。
5. open questions を残す。

## Output Format

- Summary
- Goals / Non-goals
- Proposal
- Alternatives
- Risks
- Rollout
- Open questions

## Safety

未確認の事実は assumption として明示する。
