# Implement Feature

## Objective

既存設計に沿って feature を実装し、必要な validation を実行する。

## Context To Gather

- 要件と success criteria
- 既存 entrypoint
- 関連 component/service/test
- 制約と non-goals

## Steps

1. repo context を読む。
2. 実装範囲を絞る。
3. 既存 pattern に沿って実装する。
4. 必要な test を追加または更新する。
5. validation を実行する。

## Output Format

- 変更概要
- 主要ファイル
- 実行した command
- 残リスク

## Safety

不要な refactor、global install、destructive command は避ける。
