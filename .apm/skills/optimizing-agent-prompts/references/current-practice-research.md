# Current Practice Research

最新 best practice が必要な作業では、実行時に source を確認する。

## Source Priority

1. 対象 agent vendor の official docs。
2. Agent Skills open standard や product help center。
3. 実際の repo にある既存 skill / instruction / command。
4. trusted engineering blog や release note。

## What To Extract

- skill / prompt の trigger description 要件
- file layout と naming constraints
- context management と progressive disclosure の考え方
- tool use / write safety / approval boundary
- evaluation や feedback loop の推奨

## How To Record

- 参照した source と確認日を summary に書く。
- time-sensitive な内容は `as of <date>` と明記する。
- vendor-specific rule は portable skill 本体に混ぜすぎない。
